Checkliste: neues iPad und SumUp Solo einrichten

Kasse „Olivin“ · sauna-kassensystem.web.app · Datum:   Erledigt von:

Grundregel: Händlernummer, API-Schlüssel, Affiliate-Schlüssel und das Solo gehören alle zum Sauna-Konto – nichts aus dem eigenen Test-Konto. Schlüssel nie auf diesem Blatt notieren und niemandem schicken.

A · Vorbereitung am Rechner (Sauna-Konto)

  • Anmelden bei me.sumup.com mit dem Sauna-Konto (oben rechts prüfen, dass es das Sauna-Konto ist)
  • API-Schlüssel anlegen: Profil → Einstellungen → Für Entwickler → Toolkit → API Keys → Create, Name „Kasse“. Sofort kopieren und sicher speichern (wird nicht noch einmal gezeigt). Den „Public Key“ nicht nehmen.Gespeichert in: (z. B. Passwort-Manager)
  • Affiliate-Schlüssel anlegen: Toolkit → Affiliate Keys → bei „Application identifier“ eine Kennung eintragen → Add. Diese Kennung ist später die App-ID.App-ID (genau so merken):   Schlüssel gespeichert in:
  • Händlernummer (Merchant Code) notieren – bei den Konto-/Unternehmensdaten.Händlernummer:
  • Das Solo gehört zum Sauna-Konto (dort registriert/aktiviert)

B · Das Solo vorbereiten

  • Solo laden und am Strom lassen; WLAN-Name und -Passwort bereit (sonst eigene SIM; ist beides da, nimmt es das WLAN)
  • Falls noch mit dem eigenen Konto angemeldet: oberes Menü → Einstellungen → Info → Abmelden
  • Oberes Menü → Verbindungen → WLAN verbinden → API → Verbinden. Es zeigt einen Kopplungscode (gilt nur 5 Minuten) – erst anzeigen lassen, wenn die Kasse bereit ist (Schritt D)

C · Kasse auf dem neuen iPad

  • In Safari öffnen: https://sauna-kassensystem.web.app
  • Teilen-Symbol → Zum Home-Bildschirm → Hinzufügen
  • Ab jetzt nur über das neue Symbol öffnen (die Home-Bildschirm-App hat einen eigenen Speicher)
  • Menü ☰ → Stammdaten → „Sicherung & Google“ → Abgleich einschalten und bei Google anmelden; mit dem Team-Google-Konto anmelden, Rechte bestätigen„App nicht verifiziert“ → Erweitert → Weiter. Öffnet sich kein Anmeldefenster: für heute im Safari-Tab statt über das Symbol arbeiten.
  • Warten, bis oben ☁ ✓ mit Uhrzeit steht
  • Prüfen: Kacheln, Mitarbeiter, Masseur*innen und heutige Schicht sind da · „Massageplan“ öffnet den Plan · „Termine“ öffnet den Kalender

D · SumUp in der Kasse (Menü ☰ → Stammdaten → „💳 Kartengerät“)

  • War auf einem Gerät schon ein Test-Zugang gespeichert: dort „Zugang löschen“
  • Händlernummer und API-Schlüssel eintragen → „Zugriff testen“ → Erwartung: „Zugriff funktioniert“
  • Am Solo jetzt „API → Verbinden“ drücken und den Kopplungscode ablesen (5 Minuten Zeit)
  • In der Kasse unter „Solo koppeln“: Kopplungscode + Name (z. B. „Tresen“) → Gerät koppeln → am Solo die Bestätigung abwarten
  • Nochmal „Zugriff testen“ → beim Solo „Dieses Gerät verwenden“
  • „Dauerhaft einrichten“: Affiliate-Schlüssel und App-ID (genau wie bei A) eintragen · Schalter wie voreingestellt lassen · Trinkgeld-% bei Bedarf (z. B. 5,10,15)
  • Eigenen Code (mind. 8 Zeichen) zweimal eintragen → Verschlüsselt speichernDer Code wird bei jedem Start der Kasse gebraucht. Geht er verloren: „Zugang löschen“ und neu einrichten. Code sicher aufbewahren – nicht auf diesem Blatt.

E · Echter Test (1 €)

  • Test-Gast anlegen, kleine Leistung buchen, Zahlart Karte → „An Solo senden“; am Solo mit echter Karte zahlen, Trinkgeld wählenKnopf: blau bereit → gelb gesendet → grün bezahlt (Kasse bucht Betrag und Trinkgeld)
  • Im SumUp-Konto der Sauna nachsehen: Die Zahlung steht dort – nicht im eigenen Konto
  • Bietet das Solo kein Trinkgeld an: Schalter „Trinkgeld-Voreinstellung des Solo nutzen“ ausschalten und noch einmal testen
  • Testzahlung bei SumUp erstatten, Test-Gast schließen

F · Abschluss

  • Am alten Gerät Sicherung heruntergeladen (Stammdaten → Sicherung) und dort nichts gelöscht
  • Kasse einmal komplett schließen und neu öffnen → Code wird verlangt → entsperrt → „An Solo senden“ ist wieder da
  • Zugangsdaten sind gesichert (Passwort-Manager) – nicht auf Papier, Zettel oder Chat
